# LibraryDatabase

LibraryDatabase is a backend system designed to explore and compare relational, document, and graph databases through a shared CRUD application.

## The project supports:
### MySQL
### MongoDB
### Neo4j

It also contains a migrator, that takes data from the MySQL DB, and creates + inserts the database for MongoDB and Neo4j.
This migrator is called graphMigrator but contains migration logic for both MongoDB and Neo4j.
